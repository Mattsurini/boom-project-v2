# Chinese Astrology Source Map

## Source Classes

- `calculation-backed`: deterministic output from cantian-bazi, OpenFate, or iztro.
- `external-web-material`: fetched articles/docs used for interpretation meanings.
- `synthesis`: Turboz/Boom interpretation from calculated data and source material.
- `blocked`: attempted source access failed; include reason.

## Preferred Source Order

1. Deterministic calculation output for chart/timing.
2. Official docs/tool docs for computational policy.
3. Reputable Chinese astrology references for meanings.
4. Thai-language adaptation only after source-backed meaning is clear.
