# HuangLi / Chinese Almanac — 黄历

## Project Role

HuangLi is the **practical daily electional layer** for PAC and scheduling.

Use it to answer:

- วันนี้เหมาะทำอะไร / เลี่ยงอะไร
- วันไหนเหมาะลงคอนเทนต์ / เปิดตัว / เคลียร์งาน
- clash animal / day officer / auspicious activities
- quick practical warning for audience

## Workflow

1. Query Chinese calendar/almanac data for the date.
2. Extract: lunar date, day stem/branch, clash, 宜/忌.
3. Filter through real context: PAC, content work, client readings, rest, money/admin.
4. If used for prediction, combine with BaZi day cycle and Western transit.

## Boundaries

- Almanac is not a full natal reading.
- Do not overpromise “lucky day” without matching the user’s natal chart and transit context.
- For public posts, make it practical and non-fearmongering.
