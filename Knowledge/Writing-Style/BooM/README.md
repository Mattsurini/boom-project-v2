# BooM Writing Style Library

## Purpose

เก็บตัวอย่างงานเขียนจริงของ BooM เพื่อให้ Hermes วิเคราะห์และรักษาน้ำเสียงในการเขียนงานใหม่ โดยแยกตามประเภทงาน ไม่เก็บบทความตัวอย่างทั้งหมดไว้ใน Hermes memory

## Workflow

1. BooM ส่งตัวอย่างงานเขียนทางแชตหรือไฟล์
2. เก็บเฉพาะตัวอย่างที่ BooM ยืนยันว่าเป็นเสียงของตัวเอง
3. วิเคราะห์รูปแบบเมื่อมีตัวอย่างหลายชิ้นและหลายประเภท
4. สร้างหรือปรับ `Style-Profile.md` หลังเห็น pattern ที่สม่ำเสมอ
5. ใช้ Hermes memory เก็บเฉพาะกฎสไตล์สั้นๆ ที่เป็นความชอบถาวร

## Privacy

ตัวอย่างงาน client-facing ต้องลบชื่อ ข้อมูลติดต่อ birth data และข้อมูลระบุตัวบุคคลก่อนจัดเก็บ หากเป็นงานส่วนตัวให้ระบุขอบเขตการใช้งานให้ชัดเจน
