# Knowledge Categories

This is the route hub for `E:\Boom Project\Knowledge`.

## Scope

- Every file under `Knowledge` is inventoried.
- `.pdf` files are listed by path/size/hash only; their contents are intentionally not read.
- Legacy hub/index files remain as navigation anchors.
- Non-PDF source files are physically moved into the category folders below.
- PDF files remain in their original locations and are not content-read.
- Use the category map before opening raw source files.
