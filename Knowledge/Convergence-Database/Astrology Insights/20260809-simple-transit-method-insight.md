# Reusable Insight

อ่าน Transit แบบง่ายให้ใช้ 7 ชั้น: validate natal → calculate ephemeris → overlay natal → rank slow/major/tight signals → check applying/exact/separating and retrograde → source-backed symbolic interpretation → conditional practical advice. Exactness alone is not enough; the contact must be verified and relevant to the question. Never turn a transit into a guaranteed event.

## Evidence classes
- **NotebookLM/source-grounded:** natal validation, timing funnel/layered timing, aspect/orb/phase checks, repeated hits, and anti-deterministic safeguards.
- **Calculation-backed requirement:** ephemeris, exact aspect, applying/separating, retrograde/station timing must be calculated for the actual chart.
- **Practical heuristic:** slow planets first and fast planets as triggers; useful triage, not an empirical law.
- **Unknown/limit:** NotebookLM answers are source-grounded within the notebook, not proof that astrology causes events.
