# Power Design

Brand DNA × 20 codified design principles for decks and websites.

Repo cloned at E:/Boom Project/power-design
Original https://github.com/ItsssssJack/power-design

Core: Brand DNA extraction and research-backed rules.
- 20 rules for slides
- 20 rules for web

Paths:
A Slides: 16:9 fixed, principles/design-principles.md, single HTML file.
B Websites: responsive, principles/web-principles.md, single HTML file.

Brand options: URL via Firecrawl, pick from 72+ prebuilt brands, or default.

Workflow: choose deck or website → choose brand → generate HTML meeting all 20 rules.

Key files: principles/design-principles.md, principles/web-principles.md, lib/extract-brand.md, brands/

Use for infographic decks with high data-ink, one idea per slide.
