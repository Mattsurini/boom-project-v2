# Boom Chinese Almanac

Class-level skill for Chinese calendar, HuangLi, Gan-Zhi, Wu Xing colors, and ฤกษ์/ควรทำ-ไม่ควรทำ queries in Boom Project. Uses local scripts first, cached scrapes second.

## Procedure
1. Identify date in YYYY-MM-DD. User often says DD.MM.YYYY — normalize to YYYY-MM-DD.
2. Check local cache first.
   Output/chinese_calendar_lookup.json and Output/chinese_calendar_oct2026.json contain pre-scraped facts for tarot.loveiseveryday.com/chinese-calendar.
   If date present, return facts: Gregorian, lunar month-day, ฤกษ์ของวัน, year/month/day stem-branch+element, ควรทำ, ไม่ควรทำ, วันชง, ทิศซัวะ, สีมงคล.
3. If cache miss, run local Gan-Zhi scripts with project venv.
   Working dir: E:\Boom Project
   Venv python: .venv/Scripts/python
   - Element + colors: .venv/Scripts/python scripts/chinese_almanac_accurate.py YYYY-MM-DD
   - Web-like with ควรทำ/ไม่ควรทำ: .venv/Scripts/python scripts/chinese_almanac_web_like.py YYYY-MM-DD
   - ZhDate variant: .venv/Scripts/python scripts/chinese_almanac_zhdate.py YYYY-MM-DD
4. For clothing color advice, combine Gan-Zhi day element with Boom's birth element when relevant.
   Day element from accurate script determines เสริม/เข้ากัน/ควรเลี่ยง colors per Wu Xing.
   WUXING_COLORS: wood=[เขียว], fire=[แดง,ชมพู,ม่วง], earth=[เหลือง,น้ำตาล], metal=[ขาว,ทอง,เงิน], water=[ดำ,น้ำเงิน]
   Generation rule: เสริม = element generated by day element, เข้ากัน = same element, ควรเลี่ยง = element controlled by day element.
5. If user asks kris/ฤกษ์, prioritize ควรทำ/ไม่ควรทำ from web_like or cached scrape. Note ฤกษ์ของวัน classification: วันดี หวงเต้า vs วันธรรมดา เฮยเต้า.
6. Never invent values. If script missing, state missing explicitly.

## Pitfalls
- Stem-branch calculation differs between scripts. accurate.py uses 1900-01-31 甲子日 reference. web_like.py uses delta %10/%12 from 1900-01-31. Results can differ by one day for edge cases: verify with cached scrape when color advice is critical.
- Scraped วันชง and ควรทำ/ไม่ควรทำ come from tarot.loveiseveryday.com and are Thai-specific. Do not apply to classical BaZi without noting source.
- Color mapping is Wu Xing-based, not personal BaZi luck pillars. For personal color advice combine day element with birth element only after explicit user request.
- The wrapper script chinese_almanac_wrapper.py contains mock day_branch_map and is unreliable. Prefer accurate/web_like/zhdate scripts.
