# Local vs Swiss Transit Notes

Session takeaways:

- When the user says **Local**, interpret it as the transit chart for the requested place/time, with houses recalculated for that location.
- When the user says **Swiss**, state that Swiss Ephemeris is the calculation engine and give the exact reference moment used.
- Do not confuse **local house placement** with **natal overlay**. If both are shown, label them separately.
- For the user's chart/location context in this session, Chiang Rai was used as the local reference point.
- For Pick A Card / tarot timing, a good posting window was chosen by combining:
  - Moon in a communicative house (especially 3rd)
  - Sun/Jupiter in 10th for visibility
  - avoiding hard Sun–Pluto windows when the goal is soft, accessible love content
