# Plawan Blueprint: วิธีดู Transit อย่างง่าย

## Scope
วิธีอ่าน ordinary natal transit สำหรับผู้เริ่มต้น ไม่ใช่ระบบทำนายเหตุการณ์แบบ deterministic

## Core sequence
1. ยืนยัน natal chart: เวลา สถานที่ zodiac และ house system
2. วาง current transits ทับ natal chart
3. หา slow planet → natal planet/angle ก่อน
4. จัดอันดับ major aspects: conjunction/opposition/square ก่อน trine/sextile
5. ใช้ fast planets เป็น trigger ไม่ใช่แกนเดี่ยว
6. เช็ก applying/exact/separating และ retrograde passes
7. แปลเป็น symbolic theme แล้วค่อยถามว่าเจ้าตัวควรสังเกต/จัดการอะไร

## Ignore at first
อย่าเริ่มจากทุกดาวทุกมุม, minor aspects, generic horoscope หรือ Moon อย่างเดียว

## Boundary
Transit บอกช่วงธีม/แรงกดดัน/โอกาสเชิงสัญลักษณ์ ไม่ได้พิสูจน์ว่าเหตุการณ์ใดต้องเกิด
