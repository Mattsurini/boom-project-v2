# Nan Critique — Retrograde Research

## Verdict: ⚠️ VERIFIED CORE, NEEDS SCOPE LABEL

## Approved findings

1. Retrograde is not a single meaning; it changes by interpretive layer.
2. Classical Vedic sources support motional strength and timing reversal.
3. KP supports a stricter “reject during retrogression” rule in ruling-planet/event judgment.
4. Nadi/Bhrigu supports previous-house carryover, useful for “old matter returns” readings.

## Logical gaps

- The pipeline should not overstate “retrograde = introspection.” That is a useful modern reading, not directly classical in this extraction.
- Planet-specific retrograde meanings are missing. Mars Rx, Venus Rx, Mercury Rx, Jupiter Rx, Saturn Rx need separate rules.
- Natal vs transit vs prashna/KP must not be blended. A rule from KP event timing should not be applied wholesale to natal interpretation.

## Missing dimensions

- Western sources on retrograde planets.
- Modern psychological literature on rumination/reappraisal if BooM wants a psychology-backed content series.
- Case studies: compare charts/events with retrograde dasha/transit to validate actual behavior.

## Stress-test question

If a retrograde planet has high Cheshta Bala but is debilitated/combust/in 6/8/12, what wins? Answer: no single factor wins; synthesize dignity, house, lordship, aspects, dasha, and system context.

## Approved for use

Approved as a concise research foundation and PAC/content framework, not as final doctrine.
